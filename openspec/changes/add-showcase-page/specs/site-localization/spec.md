# Spec Delta

## ADDED Requirements

### Requirement: Картинки интерфейса по языкам
Скриншоты SHALL лежать в `docs/<язык>/assets/shots/` под одинаковыми именами во всех языках. Русские скриншоты в `docs/ru/assets/shots/` — основной набор; одноимённый файл в другой языковой папке заменяет его, а при отсутствии показывается русский (`fallback_to_default`).

#### Scenario: Скриншот есть только по-русски
- **WHEN** в `docs/en/assets/shots/` нет файла `android-reports.png`, а в `docs/ru/assets/shots/` он есть
- **THEN** английская страница показывает русский скриншот по тому же относительному пути

#### Scenario: Скриншот с английским интерфейсом
- **WHEN** в `docs/en/assets/shots/` лежит `android-reports.png`
- **THEN** английская страница показывает его, а русская — свой

### Requirement: Размер и формат картинок
Картинки интерфейса SHALL быть PNG или WebP и не превышать 300 КБ каждая; скриншоты телефона сохраняются в исходных пропорциях без искажения, строка состояния системы обрезана или заменена нейтральной.

#### Scenario: Тяжёлый скриншот
- **WHEN** скриншот весит больше 300 КБ
- **THEN** он оптимизируется до публикации, иначе в репозиторий не попадает

## MODIFIED Requirements

### Requirement: Сверка переводов
`python tools/check_translations.py` SHALL сравнивать список `*.md` в `docs/ru/` с
каждой другой языковой папкой; для каждой страницы без перевода и для каждой
страницы без русского оригинала печатать предупреждение в формате GitHub Actions
(`::warning file=…::…`), в конце печатать `<язык>: <есть>/<всего> страниц`. Код
выхода — 0, а с ключом `--strict` — 1, если найдена хотя бы одна проблема.

#### Scenario: Все страницы переведены
- **WHEN** в `docs/en/` те же 15 страниц, что в `docs/ru/`
- **THEN** вывод — `en: 15/15 страниц`, предупреждений нет, код выхода 0

#### Scenario: Страница без перевода
- **WHEN** в `docs/en/` нет `features/mcp.md`
- **THEN** выведено предупреждение «нет перевода на 'en'» для `docs/ru/features/mcp.md`, код выхода 0

#### Scenario: Строгий режим
- **WHEN** есть непереведённая страница и скрипт запущен с `--strict`
- **THEN** код выхода 1
