# site-localization Specification

## Purpose
Языки сайта, структура папок, fallback на русский, единое меню, якоря и сверка переводов.

## Requirements

### Requirement: Языки сайта
Сайт SHALL быть доступен на русском (язык по умолчанию, адрес `/`) и английском
(адрес `/en/`); у каждого языка собственные `site_name` и `site_description`,
подписи переключателя темы и `nav_translations`. Названия сайта: «Посчитай и
сбереги» и «Count & Save».

#### Scenario: Английская версия
- **WHEN** открыт адрес `/en/`
- **THEN** заголовок сайта — «Count & Save», пункты меню на английском

### Requirement: Структура папок документов
Страницы каждого языка SHALL лежать в `docs/<язык>/`, а имена файлов и подпапок
во всех языках одинаковы (`docs/ru/features/ai.md` ↔ `docs/en/features/ai.md`),
чтобы переключатель языка вёл на ту же страницу.

#### Scenario: Переключение языка
- **WHEN** читатель переключает язык на странице «ИИ-помощник»
- **THEN** открывается та же страница на другом языке

### Requirement: Показ русской версии при отсутствии перевода
Если у страницы нет перевода, сайт SHALL показывать русскую версию
(`fallback_to_default: true`).

#### Scenario: Страницы нет в английской папке
- **WHEN** в `docs/en/` нет файла, который есть в `docs/ru/`
- **THEN** по адресу `/en/…` показана русская страница

### Requirement: Единое меню
Меню (`nav` в `mkdocs.yml`) SHALL быть одно на все языки и записываться по-русски; заголовки
пунктов переводятся в `nav_translations` каждого языка.

#### Scenario: Новый пункт меню
- **WHEN** в `nav` добавлен пункт
- **THEN** для каждого языка, кроме русского, в `nav_translations` добавлен перевод его заголовка

### Requirement: Явные латинские якоря
Якоря внутри страниц SHALL задаваться явно и латиницей (`## Заголовок { #statement-import }`)
одинаково во всех языках, потому что автоматические кириллические якоря MkDocs
отбрасывает.

#### Scenario: Ссылка на раздел
- **WHEN** страница ссылается на раздел другой страницы
- **THEN** ссылка использует явный якорь (например, `self-hosting.md#internet`, `ai.md#statement-import`)

### Requirement: Сверка переводов
`python tools/check_translations.py` SHALL сравнивать список `*.md` в `docs/ru/` с
каждой другой языковой папкой; для каждой страницы без перевода и для каждой
страницы без русского оригинала печатать предупреждение в формате GitHub Actions
(`::warning file=…::…`), в конце печатать `<язык>: <есть>/<всего> страниц`. Код
выхода — 0, а с ключом `--strict` — 1, если найдена хотя бы одна проблема.

#### Scenario: Все страницы переведены
- **WHEN** в `docs/en/` те же 14 страниц, что в `docs/ru/`
- **THEN** вывод — `en: 14/14 страниц`, предупреждений нет, код выхода 0

#### Scenario: Страница без перевода
- **WHEN** в `docs/en/` нет `features/mcp.md`
- **THEN** выведено предупреждение «нет перевода на 'en'» для `docs/ru/features/mcp.md`, код выхода 0

#### Scenario: Строгий режим
- **WHEN** есть непереведённая страница и скрипт запущен с `--strict`
- **THEN** код выхода 1

### Requirement: Добавление языка
Новый язык SHALL добавляться копией `docs/en/` в `docs/<locale>/` (всё
непереведённое удаляется, вместо него работает fallback) и записью в
`plugins.i18n.languages` с полями `locale`, `name`, `build: true`, `site_name`,
`site_description`, `theme.palette` и `nav_translations` для всех пунктов меню.

#### Scenario: Непереведённая страница нового языка
- **WHEN** в `docs/de/` оставлена только часть страниц
- **THEN** остальные показываются по-русски
