# Где пользоваться

=== "📱 Android"

    - Android 8.1 и новее.
    - Работает без интернета; синхронизация — в фоне.
    - Вход через Google (Credential Manager).
    - Замок приложения: цифровой код и отпечаток пальца.
    - Нижняя навигация: **Операции · Кошельки · Отчёт · Ещё**.

=== "🌐 Веб-кабинет"

    - Любой современный браузер, адаптирован под телефон.
    - Вход через Google.
    - Отчёты и аналитика, курсы, доступ и приглашения, ИИ, настройки,
      активные устройства, удаление аккаунта.

=== "💬 Telegram"

    - Бот [@WalletTransaction_bot](https://t.me/WalletTransaction_bot).
    - Подключается одноразовым кодом из веб-кабинета.

=== "🤖 ИИ-ассистенты"

    - LM Studio, Claude и другие MCP-клиенты.
    - Подключение персональным токеном из веб-кабинета.
