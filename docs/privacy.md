# Безопасность и приватность

!!! warning "Черновик"
    Это описание принципов, а не юридическая политика конфиденциальности.
    Политику для Google Play нужно готовить отдельной страницей.

- **Данные на вашем устройстве.** Приложение работает с локальной базой;
  сервер — для синхронизации и функций, которым он нужен.
- **Вход через Google** без отдельного пароля. Токены на телефоне хранятся
  в зашифрованном хранилище Android.
- **Замок приложения** — код или отпечаток.
- **Активные сессии** видны в настройках, любую можно завершить.
- **ИИ не пишет в кошелёк** и не получает ваши пропуска. По умолчанию
  работает локальная модель; облачная — только с явного согласия.
- **В журналы сервисов не попадают** ваши тексты и денежные данные.
- **MCP — только чтение**, токен отзывается в любой момент.
- **Удаление аккаунта** удаляет все данные кошелька и учётную запись.
