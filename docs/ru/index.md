# Посчитай и сбереги

**Учёт личных финансов, который работает без интернета, понимает обычную речь
и банковские выписки и одинаково доступен с телефона, из браузера и в Telegram.**

<div class="grid cards" markdown>

- :material-cellphone: **Android-приложение**

    Полноценный учёт прямо на телефоне — даже в самолёте. Данные хранятся
    на устройстве и синхронизируются, когда появляется сеть.

- :material-monitor-dashboard: **Веб-кабинет**

    Аналитика на большом экране: структура расходов, динамика, остатки по
    кошелькам, курсы валют и управление доступом.

- :material-send: **Telegram-бот**

    «Кофе 200» — и трата записана. Балансы, последние операции и вопросы
    о деньгах — не открывая приложение.

- :material-robot-happy: **ИИ-помощник**

    Пишите траты своими словами, загружайте выписку банка — ИИ разберёт
    её и разложит по категориям. Записываете всегда вы.

</div>

## Для кого

- Для тех, у кого **деньги в нескольких валютах и банках** — кошельки
  в любых валютах, переводы с конвертацией и комиссией, итог в одной валюте
  по курсу на дату.
- Для **семьи и пар** — общий кошелёк по приглашению, у каждого участника
  своя роль.
- Для тех, кому **лень вносить траты руками** — ввод фразой, голосом,
  через «Поделиться» или импорт целой выписки.
- Для тех, кто **ценит приватность** — собственный сервер, локальная
  языковая модель, ИИ не может ничего изменить в ваших данных.

## Главное за минуту

| | |
|---|---|
| **Офлайн прежде всего** | Телефон хранит всю базу и работает без сети; изменения уходят на сервер пачками и доезжают до других устройств |
| **Мультивалютность** | Любые валюты, свои валютные пары, история курсов, загрузка курсов ЕЦБ, ЦБ РФ и Yahoo Finance |
| **Один аккаунт — везде** | Вход через Google; одни и те же данные в приложении, на сайте и в боте |
| **ИИ только предлагает** | Разбор трат и выписок возвращает черновик; в кошелёк попадает только то, что вы подтвердили |
| **Отвечает на вопросы** | «Сколько ушло на еду в сентябре?» — спросите бота или своего ИИ-ассистента; суммы считает база, а не модель |
