# Свой сервер дома

!!! tip "Ваши деньги — на вашем железе"
    Сервер «Посчитай и сбереги» ставится **у вас дома** — на старый ноутбук,
    мини-ПК или домашний сервер. Никаких облаков и чужих дата-центров: база,
    отчёты и даже языковая модель работают на вашем компьютере.

## Почему дома

- **Данные никуда не уезжают.** Операции, остатки и выписки хранятся в базе
  на вашем компьютере. Их не видит ни разработчик, ни хостинг, ни облачный
  провайдер.
- **ИИ тоже дома.** Разбор трат и выписок делает **локальная языковая
  модель** на вашей видеокарте. Текст «вчера такси 450» и PDF из банка не
  отправляются в чужие нейросети.
- **Никаких подписок.** Нет ежемесячной платы за облако и нет риска, что
  сервис закроют и данные пропадут.
- **Полный контроль.** Резервные копии, обновления, кто имеет доступ — решаете
  вы.

## Сервер не обязателен

Android-приложение — полноценный учёт и **без сервера вообще**: все данные в
телефоне, работает в самолёте и на даче. Домашний сервер добавляет то, для
чего нужен «второй компьютер»:

| Без сервера | С домашним сервером |
|---|---|
| ✅ Учёт, отчёты, курсы, повторяющиеся операции на телефоне | ✅ Всё то же самое |
| ✅ Резервная копия в JSON вручную | ✅ Автоматическая синхронизация — копия всегда на сервере |
| — | ✅ Несколько телефонов и общий семейный кошелёк |
| — | ✅ Веб-кабинет с аналитикой на большом экране |
| — | ✅ Telegram-бот |
| — | ✅ ИИ: траты своими словами, импорт выписок, вопросы о деньгах |
| — | ✅ Подключение ИИ-ассистентов по MCP |

## Что нужно

| | Минимум | Для ИИ-функций |
|---|---|---|
| **Компьютер** | Любой ПК, мини-ПК или ноутбук с Linux и Docker, который может быть постоянно включён | То же |
| **Память** | 4 ГБ — сам сервер занимает около 0.5 ГБ | То же; +2 ГБ, если включать журнал событий ([ниже](#diagnostics)) |
| **Видеокарта** | Не нужна | GPU с 8 ГБ видеопамяти (например, GTX 1070) для моделей до 8B |
| **Сеть** | Домашний Wi-Fi | То же |

Без видеокарты сервер работает полностью, просто функции ИИ в приложении,
на сайте и в боте не показываются. Видеокарту можно добавить позже — ИИ
включится сам.

## Как это устроено

- Весь сервер — **один набор контейнеров** (`docker compose`): база
  PostgreSQL, сервисы учёта, отчётов, входа, ИИ, веб-кабинет и бот.
  Поднимается одной командой, обновляется сменой версии.
- **Языковая модель** запускается рядом в [LM Studio](https://lmstudio.ai) на
  том же компьютере.
- **Телефон** подключается к серверу по адресу в домашней сети: «Ещё» →
  «Интеграции». Синхронизация идёт в фоне, как только телефон оказался
  дома. Вне дома телефон продолжает работать офлайн и досинхронизируется
  по возвращении — или через ваш собственный VPN.

## Графики и журнал событий { #diagnostics }

К серверу прилагаются два **необязательных** набора для разбора проблем:

- **Графики нагрузки**: память, процессор, скорость ответов, база данных.
- **Журнал событий** с поиском по всем сервисам. Он занимает больше всего
  памяти, около 1.5 ГБ.

По умолчанию они **выключены** и сами не включаются после перезагрузки:
на домашнем компьютере память лучше оставить для работы. Сервер полностью
работает без них, а записи событий никуда не пропадают. Они копятся в
системном журнале компьютера и попадают в поиск, как только вы включите
журнал событий.

## Что всё-таки ходит в интернет { #internet }

Честный список — чтобы «никаких облаков» не было преувеличением:

| Что | Зачем | Можно обойтись? |
|---|---|---|
| **Вход через Google** | Проверка, что это вы. Google узнаёт только факт входа, не ваши финансы | Нужен для входа |
| **Курсы валют** (ЕЦБ, ЦБ РФ, Yahoo Finance) | Загрузка курсов по кнопке | Да — курсы можно вводить вручную |
| **Telegram** | Бот работает через серверы Telegram, сообщения боту видит Telegram | Да — бот необязателен |
| **Облачная модель** (Claude) | Только если вы сами выбрали её вместо локальной | Да — по умолчанию выключена |

Сами данные кошелька — операции, остатки, выписки — хранятся и
обрабатываются только на вашем сервере.
