# Валюты и курсы

- **Любые валюты** — фиатные, крипта, свои условные единицы. У каждой —
  точность (сколько знаков после запятой показывать).
- **Валютные пары** — общий справочник плюс свои пары пользователя.
- **История курсов** с графиком; курс ищется как последний известный на
  нужную дату.
- **Загрузка курсов** из открытых источников: Frankfurter (ЕЦБ), ЦБ РФ,
  Yahoo Finance. Ручной ввод и правка — на телефоне и на сайте.
- **Эквивалент** — все отчёты можно смотреть в одной выбранной валюте.
  Флаг «Показывать в эквиваленте» оставляет в выборе только нужные валюты.
- **Честные итоги** — если для пересчёта не хватает курса, итог помечается как
  неполный, а не считается «как-нибудь».
