# Подключение ИИ-ассистентов (MCP)

Подключите свой кошелёк к **LM Studio, Claude** или любому другому клиенту
с поддержкой [Model Context Protocol](https://modelcontextprotocol.io) —
и спрашивайте о своих деньгах в привычном ассистенте.

## Как подключить

1. В веб-кабинете выпустите **персональный MCP-токен**.
2. Укажите в клиенте адрес MCP-сервера и токен.
3. Спрашивайте: «сколько ушло на кафе за лето по сравнению с зимой?»

## Что умеет

| Инструмент | Назначение |
|---|---|
| `list_wallets` | Список кошельков |
| `list_categories` | Список категорий |
| `balance` | Остатки на дату |
| `spending_by_category` | Расход по категориям за период, со сравнением периодов |
| `spending_by_category_by_month` | Помесячный расход по категориям, среднее в месяц, сезонность |
| `income_expense_by_month` | Доход и расход по месяцам |
| `search_operations` | Поиск операций по тексту, с итогом |

## Гарантии

- **Только чтение** — через MCP нельзя ничего изменить.
- **Суммы считает база**, а не модель: ассистент получает готовые итоги
  с указанием периода и валюты.
- Токен можно **отозвать** в любой момент; на каждый запрос он меняется на
  короткоживущий пропуск только для чтения отчётов.
