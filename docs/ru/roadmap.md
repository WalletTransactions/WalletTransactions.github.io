# В разработке

| Что | Описание |
|---|---|
| **Комплект для установки дома** | Пошаговая инструкция и готовые образы, чтобы поднять свой сервер одной командой |
| **Долги** | Кто кому должен: долг — кошелёк человека или организации, «+» — должны вам, «−» — должны вы. Выдача и возврат — обычные переводы, поэтому доходы и расходы не искажаются |
| **Справка по продукту** | Вопрос «как это работает?» своими словами в приложении и на сайте — ответ по описанию продукта со ссылками на разделы |
| **Облачная модель Claude** | Выбор облачного провайдера ИИ с согласием на передачу данных |
| **Переводы в выписках** | Распознавание переводов между своими кошельками при импорте |
| **Управление иконками на сайте** | Загрузка и правка иконок в веб-кабинете |
