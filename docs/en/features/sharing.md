# Shared wallet

Run a budget together, as a couple or the whole family.

- **One-time invitation link** — send it through any messenger; after signing
  in the person becomes a member.
- **Roles**:

    | Role | Can |
    |---|---|
    | Owner | Everything, including managing members and transferring ownership |
    | Member | Add and edit operations |
    | Reader | View only |

- **Ownership transfer** to another member.
- Members' operations **sync** to every device: entered on one phone — seen
  on another and on the web.

Access is managed in the web dashboard, on the "Access and invitations"
screen.
