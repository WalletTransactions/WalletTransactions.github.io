# Platforms

=== "📱 Android"

    - Android 8.1 or newer.
    - Works offline; syncs in the background.
    - Sign in with Google (Credential Manager).
    - App lock: PIN code and fingerprint.
    - Bottom navigation: **Operations · Wallets · Report · More**.

=== "🌐 Web dashboard"

    - Any modern browser, phone-friendly layout.
    - Sign in with Google.
    - Reports and analytics, exchange rates, access and invitations, AI,
      settings, active devices, account deletion.

=== "💬 Telegram"

    - Bot [@WalletTransaction_bot](https://t.me/WalletTransaction_bot).
    - Linked with a one-time code from the web dashboard.

=== "🤖 AI assistants"

    - LM Studio, Claude and other MCP clients.
    - Connected with a personal token from the web dashboard.
